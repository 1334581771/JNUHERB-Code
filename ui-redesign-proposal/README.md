# JNUHERB UI 优化提案

日期：2026-10-22。状态：独立 HTML 原型与实施指南，未接入科研计算，未修改原网站。

## 打开界面

双击本文件夹的 `index.html`，用新版 Edge 或 Chrome 打开。也可以在本文件夹运行 `python -m http.server 8765` 后访问 http://localhost:8765 。无需启动 Streamlit。

可操作：首页 / 分析工作台切换、四个模块入口、三个示例预填、分析方向选择、高级参数展开、输入为空时的提示。点击“预览分析步骤”只显示建议路径，不生成结果。

HTML 原型用于确认视觉与流程，不能作为真实分析站点部署。个别模块共用演示表单；实际模块的专属输入和依赖见实施指南。原型中的数据规模沿用截图并与当前 dataset_manifest.json 的实体计数一致，没有重新扫描数据表。

## 文件

- `index.html`：已导出的浏览器预览文件。
- `ui-source.html`：易于阅读和修改的界面片段，作为设计源；不应直接替代 Streamlit 入口。
- `IMPLEMENTATION.md`：按现有代码组织的实施步骤、组件对应、状态方案与技术取舍。
- `ACCEPTANCE.md`：落地后的视觉、功能、科学结果一致性验收清单。

当前预览是直接呈现的完整 HTML，图片已经内嵌。修改设计时编辑 ui-source.html，再运行 `python refresh_proposal.py` 同步预览；正式 Streamlit 实现应按指南迁移布局和样式，不要将整站塞进 iframe。

本轮恢复原始品牌草药标记与六张实体 PNG，完整 HTML 不依赖外部字体或图标脚本。图片内嵌以便单文件预览，正式网站仍应使用现有资产加载机制。详见 `REVISION-2026-10-22.md`。

## 建议决策

优先保留 Python + Streamlit。先用主题、原生容器、真实导航与表单实现大部分视觉改进，再决定是否为网络图工具栏等少数区域增加自定义组件。完整迁移 React/Vue 不属于本提案的必要条件。
