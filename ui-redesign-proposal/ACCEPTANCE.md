# UI 实施验收清单

以下是未来正式接入的验收标准，不表示本次已经完成站点改造。

## 原型预览

- 打开 index.html 后出现完整首页，图标加载失败时文字和操作仍可用。
- 首页与工作台可互相切换；三个示例显示对应输入类型。
- 输入为空时给出明确提示；预览按钮不发起计算或伪造结果。
- 检查 1440、1024、768、390 和 320px 宽度，标题、卡片和按钮不溢出。
- 使用 Tab 键可以到达所有按钮、选择框和文本框，焦点可见。

## 正式站视觉

- 品牌绿、标题层级、圆角、间距和表格样式一致。
- 桌面首屏能看到主要研究入口，横幅不再占据大部分屏幕。
- 手机可以打开所有模块导航，不因隐藏侧栏丢失功能。
- 深色和浅色主题均检查表单、提示、图表和弹窗的可读性。
- 中英文长标题、疾病名、化学名和 ID 都可阅读。

## 正式站交互

- 模块按钮进入真实页面，不靠查找父页面 DOM 点击标签。
- 示例只预填，不自动调用 LLM、对接或分析任务。
- 普通编辑不触发昂贵计算；提交后显示实际运行状态。
- 切页不重复运行；错误可恢复，旧结果有明确归属。
- 配伍优化无上游结果时提供前置步骤；对接上传和结果选择都可达。
- 资源入口、下载和帮助都是真实可用操作。

## 科学结果一致性

- 对比同一数据快照、随机种子、输入与参数下的正向和反向案例。
- 节点、边、评分、排序、疾病靶点和富集结果与改造前一致。
- 配伍及对接保留现有参数语义和结果解释。
- 首页数据来自 manifest；实体数、关系数和原始行数不混用。
- CSV / PDF 的字段、数量及图形内容与当前任务一致。
- 两个独立浏览器会话的任务与下载不串用。

## 本次交付验证范围

交付物为 HTML 原型、可读源片段与实施文档。未运行原网站科研计算，未进行生产部署。静态语法和结构检查不等同于完整浏览器或实际 Streamlit 集成验收。
