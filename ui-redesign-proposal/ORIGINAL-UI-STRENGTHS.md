# 保留原界面优点的修订

本轮根据用户反馈恢复原界面的提示风格，仅修改独立设计稿。

## 保留的设计资产

- 🌿 JNUHERB 标识和六类实体原始插画。
- 🧪 Verified example workflows 标题与 🍵 Gui Pi Decoction、🫁 Lung cancer、😴 Insomnia 案例图标。
- Analysis Mode、🚀 Forward、🎯 Reverse 的模式识别方式。
- 正向与反向的完整关系路径说明。
- 每行一项、ID 类型、模式默认阈值和可选筛选条件等必要提示。

## 信息层级

侧栏恢复分析方向与一句完整路径说明，输入及较长帮助保留在工作台，避免首页侧栏过长。提示按三层安排：默认显示方向与输入规则；字段邻近说明解释格式和匹配；可选筛选展开后解释阈值和优先级。精简视觉不应删减完成任务所需信息。

小图标用于识别模式、案例、模块和提示；保留文字标签，不单靠 emoji 传达含义。不要给每句话增加图标，以免形成新的噪声。

## 原型边界

Verified 沿用原项目案例名称，不能理解为本轮重新执行了验证。原型只预填和展示帮助；无真实评分、疾病解析、模型或对接调用。正式站需复用现有案例配置及 pending_prefill 机制，完整载入参数。

归脾汤示例在原型中预填 HVP5811。正向默认评分与单体差异、疾病优先于手动靶点等提示来自本轮核对的现有源码，正式实现仍应与业务参数配置共享来源，避免帮助文案与计算逻辑分离维护。
